# BuffettChart

独立的巴菲特指数半静态展示页，挂载路径 `/buffett/`。顶部显示标准指数、去趋势偏离、同季长期趋势及 Z-score；正文仅显示标准与去趋势两张全历史图。支持桌面及手机，图表为可下载的 SVG，手机可横向查看完整图。

当前输入是迁移包的冻结 v1：1952Q1—2026Q2，共 298 季。2026Q2 标准指数 238.425816%，去趋势偏离 +65.930183%，趋势 143.690444%，Z-score +1.495685。数据快照更新日为 2026-10-07，网页构建和发布不会改变该日期，也不代表实时估值。

## 构建与本地查看

需要 Node.js 22 或更高版本，无第三方运行依赖。

```sh
npm run build
npm test
npm run preview
```

访问 `http://127.0.0.1:4173/buffett/`。`dist/` 是完整静态发布目录，可复制到任意站点的 `/buffett/` 下，页面资源使用相对 URL。顶部总览与个股监察链接用于现有个人工作台。

## 五个月更新提示

以 `data/manifest.json` 的 `updated_on` 为数据快照最后核验/更新日，按照 Asia/Shanghai 的日历日期加 5 个月（月底截到目标月末）。**超过**该日期后提示“数据超过 5 个月未更新，请更新后再观察”。2026-10-07 的快照到 2027-03-07 当天仍未超过，2027-03-08 00:00 上海时间开始警告。

浏览器首次打开、切回页面以及每分钟重新检查。停留在旧页面也会变更提醒。没有 JavaScript 时仍可看图、读数，并显示明确的人工核查期限。提示不会隐藏或擅自刷新原值。

## Cloudflare 入口接入

```sh
npm run build
npm test
npm run integrate -- G:/cloudflare/myapp
```

脚本向现有 `myapp/public/buffett/` 导入白名单静态文件、增加独立路由处理器、首页卡片与全站导航，并记录文件哈希。它复用已存在的 `STOCKCHECK_ASSETS` 绑定和 `run_worker_first`，不修改 Wrangler 绑定、D1、KV 或 Access。然后在 myapp 运行 `npm test` 和 `npm run check`。

代码提交与 Cloudflare 正式部署是两个步骤，本项目不自动部署。详见 [Cloudflare 接入说明](docs/cloudflare.md)。

## 数据与模型维护

- `data/Buffett_Quarterly_Frozen_v1.json` 为原始固定输入，SHA-256 为 `811a45df3978d0e4e41d85012a737683014f5eba579ba5584a92536e2af68b1a`，构建前强制检查。
- 标准指数 = 市值（百万美元）/1000/GDP（十亿美元 SAAR）×100。GDP 不再乘 4。
- 全历史拟合 `ln(BI)=a+b*t`，t 每季递增 0.25 年。σ 为对数回归残差的标准差，分母 n−2。
- 去趋势 = `(BI/Trend−1)×100`；Z = `ln(BI/Trend)/sigma_log`。百分比与 Z 不混用。σ 带不是置信区间或概率。
- 1952Q1—1996Q3 共 179 季历史估计及固定系数永久冻结，已有 298 行基线不覆盖。
- 新季度或采纳的官方修订需要独立输入版本、来源信息与差异记录；修订采纳由用户决定。随后明确升级构建的版本合约与验收参数，不能绕过当前 v1 哈希检查。此版本没有自动抓取新数据的功能。
- 更新数据时，`updated_on` 必须记录实际数据快照核验日；仅重画、样式变更、部署或重新构建不得刷新它。当前 v1 强制与输入 `captured_on` 一致。

`archive/` 保留完整原始迁移包、原交接文档和 v2 规范。原 v2 三图与离线 Python 入口仍在迁移包中。本次网站规范只显示两张全历史图；近期 40 季图作为归档保留，不在本页面展示。

## 目录

| 路径 | 用途 |
| --- | --- |
| `src/` | 页面模板、样式、浏览器更新提示 |
| `scripts/model.mjs` | 只读数据验证与共享模型 |

| `tests/` | 日期边界、原值保护、模型回归、构建与路由测试 |
| `archive/` | 原始迁移资料，仅源码归档，不部署 |
